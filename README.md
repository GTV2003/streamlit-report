# Доклад о Streamlit

11 слайдов с работающими примерами и общий квиз по пяти вопросам из исходной презентации. Последний экран показывает QR до старта и доску результатов во время квиза.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте [презентацию](http://localhost:8501/). Для выступления откройте [первый слайд в режиме ведущего](http://localhost:8501/?presenter=1&slide=1). При первом входе приложение создаёт код в `runtime/host_code.txt`.

## Как провести квиз

1. На 12-м слайде покажите QR. Его можно заранее открыть во второй вкладке по [ссылке участника](http://localhost:8501/?join=1). Для телефонов нужен адрес приложения, доступный из их сети. QR берёт адрес из браузера ведущего. При необходимости его можно изменить под QR в настройках раунда.
2. Нажмите «Старт». У слушателей закроются слайды и появится форма ФИО, затем пять вопросов по одному. Одинаковые ФИО допускаются. Личная ссылка с билетом позволяет вернуться к своей попытке после обновления страницы.
3. На доске появляются имена и прогресс. После пятого ответа участник попадёт в облако имён и в распределение баллов. «Завершить приём ответов» открывает разбор, «Новый раунд» сохраняет прежние попытки и готовит следующий запуск.

Раунды и ответы хранятся в `runtime/quiz.sqlite3`. Для сервера с постоянным диском можно задать `QUIZ_DATA_DIR`, `QUIZ_HOST_KEY` и `PUBLIC_APP_URL`. Старые ссылки с `?quiz=1` по-прежнему ведут в квиз.

Проверки запускаются командой `python -m unittest -v test_live_quiz` и используют временные базы.
